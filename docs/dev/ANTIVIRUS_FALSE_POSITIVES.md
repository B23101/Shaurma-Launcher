# Хибні спрацювання антивірусів

Актуалізовано 2026-10-31 за публічним кодом. Антивірусний вердикт потрібно
розслідувати для конкретного файла; ця документація не доводить його безпечність.

## Захист оновлень

Production bootstrap, shell та updater вимагають підписаний Ed25519 маніфест.
Контекст підпису — `shaurma-launcher-manifest-v1\n`, далі точні байти маніфесту.
Публічні ключі вшиваються під час збірки. Публічний Windows build-скрипт
відхиляє відсутні ключі навіть без `-RequireSecrets`, а також некоректні ключі.
Production-код не переходить на непідписані маніфести за відсутності ключів.
SHA-256 і розмір компонентів перевіряються до їх встановлення; невідповідність
блокує оновлення. Попередні твердження про «м’яку» перевірку та обхід підпису
застаріли. Токен CDN не доводить цілісність і не замінює підпис.

## Authenticode

GitHub Actions спочатку подає на SignPath shell, bootstrap, backend.dll і
updater.dll, перевіряє підписи та метадані, потім збирає і підписує інсталятор.
Конфігурації лежать у `.signpath/artifact-configuration/`. Активація сервісу й
ручне схвалення кожного запиту виконуються окремо. Dry run лишається непідписаним.
Підпис bootstrap обов’язковий: підпис setup не замінює підпис вкладеного EXE.
Таймстемпи змінюють підписані байти; постійний хеш setup не гарантується.

Скрипти збирають production-код із `-trimpath`, `-buildvcs=false`, `-buildid=`;
EXE використовують PIE, DLL — необхідний `c-shared`. Це саме по собі не доводить
побайтову відтворюваність cgo, ZIP та Inno Setup на різних середовищах.
Приховані PowerShell/cmd із лаунчера не потрібні й не повинні додаватися.

## Перевірка перед публікацією

1. Успішний CI, production-тести підписів і перевірка політики збірки.
2. Підписаний beta-випуск: перевірка Authenticode всіх п’яти PE, видавця та метаданих.
3. Чиста Windows: установка, перший запуск, оновлення, відмова при підміні
   маніфесту/підпису/компонента, видалення власних правил firewall.
4. За підтвердженого хибного спрацювання подати остаточний підписаний файл
   виробнику антивіруса через його офіційний канал. Додати версію, SHA-256,
   посилання на джерела й опис завантаження компонентів. Не просити вимикати захист.
