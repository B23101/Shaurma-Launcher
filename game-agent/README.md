# Shaurma Game Agent

Один `-javaagent` jar для **Minecraft 1.16.5+ і всіх лоадерів** (Fabric, Quilt, Forge, NeoForge; також ваніла).
Працює на рівні JVM і LWJGL/GLFW, а не на рівні класів Minecraft, тому не залежить ні від версії гри, ні від лоадера.

Лаунчер підкладає агента **лише у запуски, ініційовані ШІ-агентом** (MCP), і лише під окремим акаунтом
(за замовчуванням `Claude`, офлайн) — ніколи під акаунтом гравця.

## Що вміє
| Команда | Опис |
|---|---|
| `status` | FPS (поточний, середній, 1% low, час кадру), розмір вікна, JVM (heap, GC, потоки, CPU), список модів лоадера, заблоковані з'єднання |
| `screenshot` | окремий кадр (`glReadPixels` перед показом): не потрапляє в папку скріншотів, вікно може бути позаду |
| `key` | клавіша (tap / press / release, hold_ms, модифікатори) |
| `type`, `chat` | введення символів; чат із відкриттям (`T` або `/`) та Enter |
| `mouse_move` | відносний (камера) або абсолютний (GUI) рух курсора |
| `mouse_click`, `scroll` | кнопки миші й колесо |

Ввід подається викликом справжніх callbacks GLFW гри на потоці рендеру, тож справжню мишу й клавіатуру гравця агент не чіпає.
Втрата фокусу вікна ігнорується (гра не стає на паузу, поки вікно позаду). Вікно **не можна згортати**.

## Безпека
- Керуючий інтерфейс слухає лише `127.0.0.1`, потрібен токен (`X-Shaurma-Token`); запити з `Origin` і з чужим `Host` відхиляються.
- Без коректних `port`, `token`, `nick` агент нічого не вмикає.
- **Мережева заборона неможлива до вимкнення:** гра може підключатися лише до локальних адрес (loopback, приватні мережі, link-local, IPv6 ULA).
  Публічні сервери, ботнети й сторонні HTTP-запити блокуються на рівні `Socket.connect` / `SocketChannel.connect` / Netty epoll.
- Використання керування вводом на чужих серверах може порушувати їхні правила; тому ШІ дозволено лише локальні світи й сервери.

## Збірка
```
cd game-agent
mvn -B verify          # JDK 17+; байткод Java 8; звіти — target/surefire-reports/
```
Результат: `target/shaurma-game-agent.jar` (ASM вшито з перейменованим пакетом). У репозиторій jar не комітиться:
його збирає та публікує GitHub Actions (`.github/workflows/game-agent.yml`).

## Аргументи агента
`-javaagent:shaurma-game-agent.jar=port=NNNN;token=XXXXXXXXXXXXXXXX;nick=Claude`
(`token` — 16–128 символів `A-Za-z0-9_-`, `nick` — 3–16 символів `A-Za-z0-9_`).
